使用说明

85% 指 CPU 与 GPU 的目标工作比例上限，不是整机占用率。

选择档位和时间，按电源开启。再次按电源停止。CPU、GPU 均关闭时只展示炉火。

开始时会根据浏览器提供的逻辑处理器数量和短时校准自动分配任务，再根据响应速度调节。GPU 型号以浏览器实际提供的信息为准；无法读取完整硬件配置或温度。

GPU 使用 WebGL2，需要浏览器开启硬件加速；不支持时会提示，不会用软件计算冒充 GPU。
